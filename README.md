# PRODIGY_DS_02

## Task 02 - Titanic Dataset EDA

Performed data cleaning and exploratory data analysis (EDA) on the Titanic dataset using Python.

## Tasks Performed

* Checked missing values
* Analyzed dataset statistics
* Created survival analysis graphs
* Explored gender-based survival rates
* Visualized passenger age distribution

## Tools Used

* Python
* Pandas
* Matplotlib
* Google Colab

## Key Insights

* More passengers died than survived
* Females had higher survival rates
* Most passengers were between age 20–40
* Missing values existed in Age and Cabin columns
